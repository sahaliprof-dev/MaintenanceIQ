Calculer le MTBF, le MTTR et la disponibilité d’une machine

Trois indicateurs suffisent pour savoir si une machine se dégrade : le temps moyen entre deux pannes (MTBF), le temps moyen pour la remettre en marche (MTTR) et la disponibilité qui en découle. Suivez-les chaque mois, machine par machine.

La formule

MTBF = (temps d’ouverture − temps d’arrêt) / nombre de pannes ; MTTR = temps d’arrêt / nombre de pannes ; disponibilité = MTBF / (MTBF + MTTR).

Exemple chiffré

720 h d’ouverture, 3 pannes et 12 h d’arrêt : MTBF = 708 / 3 = 236 h, MTTR = 12 / 3 = 4 h, disponibilité = 236 / 240 ≈ 98,3 %.

Questions fréquentes

Faut-il compter les arrêts programmés ?

Non : seuls les arrêts dus à des pannes entrent dans ce calcul. Les arrêts de maintenance préventive se suivent à part.

Quelle disponibilité viser ?

Il n’y a pas de valeur universelle : elle dépend de la machine et du coût d’un arrêt. Comparez surtout la machine avec elle-même dans le temps.

Résultat indicatif, calculé sur votre téléphone : rien n’est envoyé. La notice du constructeur et les règles de votre site passent avant.
