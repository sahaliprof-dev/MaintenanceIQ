Rank your machines by criticality in 10 minutes

Level: Simple Maintenance method · by SAHALI, MaintenanceIQ

You cannot monitor everything with the same attention, and you do not need to. Score each machine from 1 to 3 on four criteria, add them up, and you know where to focus.

The four criteria

Criterion1 point2 points3 points
Production impactNone or lowSlows activityStops activity
Safety and environmentNo riskLimited riskRisk to people, leak, fire
Parts and repair timeIn stock, a few hoursA few daysImported, several weeks
BackupDuplicate machinePartial or manual backupNo backup

Reading the score

  • 10–12, class A (critical): weekly readings, full machine record, critical spares in stock.
  • 7–9, class B: readings every two weeks, weekly visual and listening check.
  • 4–6, class C: monthly check, greasing as per manufacturer.

Example

The water transfer pump of a bottling plant, with no backup, whose motor takes three weeks to import: 3 + 2 + 3 + 3 = 11, class A. A changing-room fan: 1 + 1 + 1 + 2 = 5, class C.

Frequently asked questions

Should the grid be redone regularly?

Yes, whenever things change: a new backup machine, a part now stocked, reorganised production.

What comes first for a class A machine?

Record its baseline readings while it runs well, and make sure its critical spares are available.
